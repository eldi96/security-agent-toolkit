| 표시 | 명칭 | 의미 |
| :---: | :--- | :--- |
| **A** | Added | 스테이징 영역에 추가된 새 파일 (`git add` 완료) |
| **M** | Modified | 기존 파일의 내용이 수정됨 |
| **U** | Untracked | 새로 작성되어 Git이 아직 추적하지 않는 파일 |
| **D** | Deleted | 파일이 삭제됨 |
| **R** | Renamed | 파일 이름이 변경되었거나 이동됨 |
| **C** | Conflict | 병합(Merge) 중 충돌이 발생함 |
| **I** | Ignored | `.gitignore`에 의해 추적에서 제외됨 |
