# Day 01. Python 기초 문법과 개발환경

> 2026-09-22 · AI 자동화를 위한 Python

## 오늘의 학습

변수와 자료형부터 시작해 값을 저장하고 꺼내는 방법을 배웠다. `int`, `float`, `str`, `bool`의 차이와 형변환, f-string을 확인했다. 이후 리스트와 딕셔너리로 여러 정보를 묶어 관리하고, 오류 종류와 가상환경까지 살펴봤다.

## 실습 흐름

변수·자료형 → 형변환 → 리스트·딕셔너리 → 오류 확인 → 개발환경·가상환경

## 기억할 코드

**리스트와 딕셔너리에서 값 꺼내기**

```python
users = [{"name": "kim01", "fail": 2}]
print(users[0]["name"])
```

**없는 키에 대비하기**

```python
user = {"name": "kim01"}
print(user.get("fail", 0))
```

## 오늘 막혔던 부분

리스트는 순서로, 딕셔너리는 키로 접근한다는 차이를 정리했다. `KeyError`처럼 없는 키를 조회하는 상황에는 `.get()`을 사용할 수 있다는 점도 확인했다. 실제 질문에서 별도로 확인된 어려움은 없어 학습 메모 위주로 남긴다.
