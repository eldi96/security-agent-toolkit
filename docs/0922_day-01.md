## 오늘의 학습

변수와 자료형부터 시작해 값을 저장하고 꺼내는 방법을 배웠다. `int`, `float`, `str`, `bool`의 차이와 형변환, f-string을 확인했다. 이후 리스트와 딕셔너리로 여러 정보를 묶어 관리하고, 오류 종류와 가상환경까지 살펴봤다.

## 학습 내용

### Python에서 값을 다루는 기본 방식

처음에는 변수에 값을 담는 것부터 시작했다. 변수는 값을 보관하는 상자라기보다 **값을 가리키는 이름**에 가깝고, 같은 이름에 새로운 값을 대입하면 이후에는 새 값을 사용한다. `=`는 대입, `==`는 비교라는 구분도 이후 조건문을 배울 때 중요해지는 기초다.

자료형은 `int`(정수), `float`(실수), `str`(문자열), `bool`(참·거짓)을 중심으로 확인했다. 숫자처럼 보이는 문자열은 계산할 때 숫자로 변환해야 하고, 출력 문장에서는 `str()`이나 f-string을 활용할 수 있다. `int("7")`은 숫자 7이 되지만 숫자로 바꿀 수 없는 문자열은 오류가 난다.

### 여러 값을 저장하는 자료구조

리스트는 여러 값을 순서대로 저장하고 **인덱스**로 접근한다. 딕셔너리는 `키: 값` 형태로 저장하고 **키**로 접근한다. 보안 로그처럼 사용자마다 이름·접속 횟수·IP 등 여러 항목이 있을 때 딕셔너리가 유용하고, 여러 사용자 기록을 모으면 리스트 안에 딕셔너리를 넣는 형태가 된다.

`user["name"]`처럼 키를 직접 조회할 때 키가 없으면 `KeyError`가 발생한다. 값이 없을 수 있는 항목은 `user.get("fail", 0)`처럼 기본값을 지정할 수 있다. 오류도 모두 같은 종류가 아니라 `NameError`, `TypeError`, `SyntaxError`, `KeyError` 등 원인에 따라 다르게 나타난다는 점을 정리했다.

### 코드를 실행하는 환경

Python 코드와 이를 실행하는 환경도 함께 살펴봤다. 스크립트는 `.py` 파일, 터미널은 명령을 입력하는 창, `pip`는 외부 패키지 설치 도구다. 가상환경은 프로젝트별로 패키지 설치 범위를 나누는 방법이다. Colab에서 실습하는 것과 로컬 터미널에서 파일을 실행하는 것은 실행 환경이 다를 수 있다는 점도 기억할 내용이다.

## 실습 흐름

변수·자료형 → 형변환 → 리스트·딕셔너리 → 오류 확인 → 개발환경·가상환경

## 기억할 코드

**리스트와 딕셔너리에서 값 꺼내기**

```python
users = [{"name": "kim01", "fail": 2}]
print(users[0]["name"])
```

**없는 키에 대비하기**

```python
user = {"name": "kim01"}
print(user.get("fail", 0))
```

## 실습에서 연결된 내용

처음 배운 문법이지만 뒤의 로그 분석 실습까지 연결되는 출발점이었다. 특히 **리스트는 번호로, 딕셔너리는 키로 접근한다**는 차이는 이후 중첩 JSON을 읽을 때 계속 등장한다. 개발환경 관련 내용은 코드를 작성하는 것과 실행·패키지 관리가 별개의 작업임을 이해하는 데 의미가 있었다.

## 오늘 막혔던 부분

리스트는 순서로, 딕셔너리는 키로 접근한다는 차이를 정리했다. `KeyError`처럼 없는 키를 조회하는 상황에는 `.get()`을 사용할 수 있다는 점도 확인했다. 실제 질문에서 별도로 확인된 어려움은 없어 학습 메모 위주로 남긴다.
