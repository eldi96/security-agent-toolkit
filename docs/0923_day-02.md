# Day 02. 조건문·반복문과 함수

> 2026-09-23 · AI 자동화를 위한 Python

## 오늘의 학습

`if` 조건문과 비교·논리 연산자로 실행할 작업을 고르고, `for`·`while`로 반복 처리하는 방법을 익혔다. 집합과 `Counter`로 중복과 횟수를 다루고, 반복되는 작업을 함수로 분리했다. 이어 모듈을 불러오고 CSV 파일을 읽는 흐름까지 살펴봤다.

## 학습 내용

### 조건에 따라 다른 작업 실행

`if`, `elif`, `else`를 사용해 조건이 참인지에 따라 실행 경로를 나누었다. `if` 뒤에는 콜론(`:`)이 필요하고, 조건에 속하는 코드는 들여쓰기로 구분한다. `=`는 값을 넣는 대입 연산자, `==`는 두 값이 같은지 확인하는 비교 연산자다.

여러 조건을 조합할 때는 `and`, `or`, `not`을 사용했다. 예를 들어 로그인 실패 횟수가 기준 이상이면서 특정 계정에 해당하는지를 동시에 검사할 수 있다. `in`과 `not in`은 문자열이나 컬렉션에 값이 들어 있는지 확인할 때 사용한다.

### 반복·집계·임계값

`for`는 목록의 항목을 하나씩 꺼내 처리하고, `while`은 조건이 참인 동안 반복한다. `range()`로 반복 횟수를 만들 수 있으며 시작·끝·간격을 지정할 수 있다. 여러 로그를 순서대로 확인하면서 실패한 계정만 고르는 작업에 반복문과 조건문을 함께 사용했다.

`set`은 중복된 값을 제거할 때, `collections.Counter`는 값별 등장 횟수를 셀 때 활용했다. 로그인 실패 횟수가 `THRESHOLD` 같은 기준에 도달했는지 판단하는 흐름으로 이어졌다. 임계값은 코드 곳곳에 직접 적기보다 의미 있는 이름으로 분리하는 편이 수정하기 쉽다.

### 함수를 만들고 파일을 다루기

`def`로 반복 작업에 이름을 붙이고, 매개변수로 값을 전달하며 `return`으로 결과를 돌려받는 방법을 배웠다. `print()`는 화면에 보여주는 것이고 `return`은 호출한 코드가 결과를 다시 사용하게 하는 것이라는 차이가 중요했다.

이후 `import`로 다른 모듈의 기능을 불러오고 `csv`, `datetime`, `collections` 같은 표준 라이브러리를 확인했다. CSV는 첫 줄의 헤더를 기준으로 열을 구분하며, `csv.DictReader`를 쓰면 각 행을 딕셔너리처럼 다룰 수 있다. Colab에서 코드를 `.py` 파일로 저장하고 다시 실행하는 흐름도 강의 자료에 포함되어 있었다.

## 실습 흐름

조건 판단 → 반복 처리 → 중복·횟수 계산 → 함수로 분리 → 모듈·CSV 활용

## 기억할 코드

**로그를 하나씩 확인**

```python
logs = ["INFO", "WARN", "ERROR"]
for log in logs:
    if log != "INFO":
        print(log)
```

**함수의 입력과 반환**

```python
def add(a, b):
    return a + b

print(add(2, 3))
```

## 실습에서 연결된 내용

조건문과 반복문을 따로 배우는 데서 끝나지 않고, **로그를 한 줄씩 검사해 조건에 맞는 항목을 모으고 횟수를 세는 작업**으로 연결했다. 다음에는 그 과정을 함수로 묶어 재사용하고, CSV 같은 파일에서 입력을 받아 처리할 수 있다는 흐름이 잡혔다.

## 오늘 막혔던 부분

함수에 매개변수를 두 개만 선언하면 두 값만 더하는지, 더 많은 값을 전달하려면 어떻게 해야 하는지 질문했다. 매개변수 개수는 함수 정의에 따라 정해지고, 여러 값을 다루려면 리스트 등을 받거나 가변 인자를 사용할 수 있다는 방향으로 정리했다.
