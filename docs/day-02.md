# Day 02. 조건문·반복문과 함수

> 2026-09-23 · AI 자동화를 위한 Python

## 오늘의 학습

`if` 조건문과 비교·논리 연산자로 실행할 작업을 고르고, `for`·`while`로 반복 처리하는 방법을 익혔다. 집합과 `Counter`로 중복과 횟수를 다루고, 반복되는 작업을 함수로 분리했다. 이어 모듈을 불러오고 CSV 파일을 읽는 흐름까지 살펴봤다.

## 실습 흐름

조건 판단 → 반복 처리 → 중복·횟수 계산 → 함수로 분리 → 모듈·CSV 활용

## 기억할 코드

**로그를 하나씩 확인**

```python
logs = ["INFO", "WARN", "ERROR"]
for log in logs:
    if log != "INFO":
        print(log)
```

**함수의 입력과 반환**

```python
def add(a, b):
    return a + b

print(add(2, 3))
```

## 오늘 막혔던 부분

함수에 매개변수를 두 개만 선언하면 두 값만 더하는지, 더 많은 값을 전달하려면 어떻게 해야 하는지 질문했다. 매개변수 개수는 함수 정의에 따라 정해지고, 여러 값을 다루려면 리스트 등을 받거나 가변 인자를 사용할 수 있다는 방향으로 정리했다.

## 핵심 정리

- 조건 판단 / 반복 처리 / 중복·횟수 계산 / 함수로 분리 / 모듈·CSV 활용
