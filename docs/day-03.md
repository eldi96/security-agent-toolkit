# Day 03. 예외 처리와 로그 데이터 정규화

> 2026-09-28 · AI 자동화를 위한 Python

## 오늘의 학습

실제 로그에는 파일 누락, 칸 부족, 숫자 변환 실패 같은 문제가 생길 수 있다는 점을 배웠다. `try/except`로 예외를 처리하고 `logging`으로 상황을 기록했다. 이후 CSV 문자열을 나누고 딕셔너리로 바꾼 뒤, 중첩 구조와 JSON을 사용해 데이터를 저장하는 과정을 실습했다.

## 실습 흐름

오류 확인 → 예외 처리 → 로그 기록 → 문자열 분리 → 딕셔너리 변환 → JSON 저장

## 기억할 코드

**깨진 로그 건너뛰기**

```python
try:
    count = int("abc")
except ValueError:
    print("숫자로 변환할 수 없음")
```

**문자열을 딕셔너리로 정리**

```python
keys = ["time", "user", "event"]
values = "09:12,admin,login_fail".split(",")
row = dict(zip(keys, values))
```

## 오늘 막혔던 부분

중첩 딕셔너리에서 `report["admin"]["fail"]`처럼 대괄호를 연속해서 사용하는 과정이 헷갈렸다. 안쪽 값이 다시 딕셔너리라는 점을 확인하고, 문자열을 `split()`으로 리스트로 만든 다음 `zip()`과 `dict()`로 키·값을 연결하는 흐름을 따라가며 이해했다.
