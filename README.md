# Security Agent Toolkit

SKT ALEPH 교육 과정에서 진행한 Python 및 보안 자동화 실습을 기록한 저장소입니다.

Python 기초부터 API 통신, 데이터 처리, 보안 이벤트 분석까지 학습하며 작성한 코드와 일별 학습 기록을 정리했습니다.

## 📚 Learning Topics

| 분야 | 주요 학습 내용 |
|---|---|
| Python Basics | 변수, 자료형, 조건문, 반복문, 함수 |
| Data Processing | 리스트, 딕셔너리, JSON, 정규표현식 |
| Error Handling | 예외 처리, 로깅, 파일 입출력 |

| Security Automation | 이벤트 정규화, 탐지 규칙, 경보 처리 |
| AI Integration | LLM API 호출, 응답 파싱, 보안 이벤트 요약 |

## 🛠 Practice Highlights

**HTTP & API Communication**

HTTP 요청과 응답 구조를 이해하고, Python을 이용한 API 통신 및 웹훅 서버 실습을 진행했습니다.

**Security Event Processing**

보안 이벤트를 일정한 형식으로 정규화하고, 탐지 규칙을 적용하여 이벤트를 분류하는 과정을 학습했습니다.

**AI-based Event Analysis**

LLM을 활용한 보안 이벤트 요약과 응답 데이터 처리 과정을 실습했습니다.
